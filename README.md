# فريق أبناء الأرض التطوعي — SOL Team 2026

منصة عربية متكاملة مبنية بـ Next.js 14 + Supabase لعرض الفريق والمتطوعين والمبادرات والأثر المجتمعي واستقبال طلبات الانضمام، مع لوحة إدارة مخفية ومحمية بجلسة خادم.

## أهم التغييرات في هذه النسخة

- إلغاء تسجيل دخول وحسابات المتطوعين بالكامل من تجربة الموقع.
- الانضمام أصبح نموذجاً عاماً من 3 خطوات بدون إنشاء حساب.
- دخول الإدارة: اضغط على شعار الفريق 7 مرات خلال عدة ثوانٍ، ثم أدخل كلمة المرور `sol.`.
- كلمة المرور لا تُرسل مع كل عملية تعديل ولا توضع في روابط الحذف؛ بعد الدخول يتم إنشاء جلسة Admin عبر HttpOnly Cookie لمدة 12 ساعة.
- لوحة إدارة موحدة للمتطوعين والمبادرات وطلبات الانضمام وإعدادات الموقع ولوحة المؤشرات.
- صفحة إعدادات عامة لتعديل اسم الفريق، الاسم المختصر، الشعار النصي، الوصف، الموقع، الهاتف، إنستغرام، تاريخ التأسيس، الموعد المهم، ونص دعوة الانضمام.
- تحسين واجهة الهاتف والقائمة الرئيسية والتباعد والخط العربي وتجربة الصفحات العامة.
- إحصائيات الصفحة الرئيسية أصبحت تعتمد على البيانات الفعلية عندما تكون Supabase متصلة بدل أرقام ثابتة قدر الإمكان.
- تحسين التحقق من نموذج الانضمام ومعالجة الطلب المتكرر بشكل أوضح.
- بقاء مزايا المتطوعين الحالية: الملفات الشخصية، بطاقات العضوية، QR، PDF، البحث، التصويت لنجم الأسبوع، Dark Mode وPWA.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## متغيرات البيئة

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
ADMIN_PASSWORD=sol.
ADMIN_SESSION_SECRET=ضع_هنا_سلسلة_عشوائية_طويلة_جداً
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

> `ADMIN_PASSWORD` مضبوط على `sol.` حسب إعداد المشروع المطلوب. لا تضع `SUPABASE_SERVICE_ROLE_KEY` داخل أي متغير يبدأ بـ `NEXT_PUBLIC`.

## تحديث قاعدة البيانات

**إذا كان لديك مشروع Supabase موجود مسبقاً وفيه بيانات حقيقية** شغّل فقط الملف الآمن التالي من SQL Editor:

```text
supabase/upgrade_2026_10_sol.sql
```

هذا التحديث غير هدّام ويضيف جدول إعدادات الموقع فقط بدون حذف أو تعديل سجلات المتطوعين والطلبات الحالية.

أما عند إنشاء مشروع Supabase جديد وفارغ من الصفر، يمكن تشغيل:

```text
supabase/schema.sql
```

## دخول الإدارة

1. افتح أي صفحة عامة في الموقع.
2. اضغط على شعار الفريق في الهيدر 7 مرات متتالية.
3. ستظهر نافذة دخول الإدارة.
4. أدخل كلمة المرور `sol.`.
5. بعد النجاح تنتقل إلى `/admin/dashboard`.

لا يوجد رابط إدارة ظاهر للزائر، كما أن صفحات `/admin/*` نفسها تتحقق من جلسة الإدارة على الخادم.

## أقسام لوحة الإدارة

- `/admin/dashboard` — لوحة المؤشرات والاختصارات.
- `/admin` — إضافة وتعديل وحذف المتطوعين ورفع/قص الصور وتغيير الحالة والترتيب والفرق والإنجازات.
- `/admin/initiatives` — إدارة المبادرات والحالة ونسبة الإنجاز والمستفيدين والساعات.
- `/admin/applications` — مراجعة طلبات الانضمام، البحث والتصفية، الملاحظات، القبول والرفض وحالة التواصل.
- `/admin/settings` — تعديل معلومات وهوية الموقع العامة بدون تعديل الكود.

## ملاحظات النشر

- بعد تحديث المشروع أعد نشره على Vercel أو الخادم المستخدم.
- على مشروع Supabase الحالي شغّل `supabase/upgrade_2026_10_sol.sql` فقط.
- اضبط `ADMIN_SESSION_SECRET` بقيمة طويلة عشوائية في الإنتاج.
- رفع صور المتطوعين يقبل JPG / PNG / WEBP حتى 2MB.
